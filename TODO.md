# Видалення програм — план

Нова вкладка «Програми» (і CLI `macjanitor apps`). Дві частини: видалення програми і перегляд залишків після нього, кожну з окремою дією. Реалізовувати по одному пункту за раз.

## Список програм

- [x] Список встановлених програм з `/Applications` і `~/Applications` (Fusion ставить ярлики саме в `~/Applications`), з назвою, bundle id, версією, розміром і датою останнього запуску.
- [ ] Рахувати справжній розмір: якщо `.app` є symlink або ярликом, показувати розмір цілі (Fusion: ярлик 0 Б, сама програма 4.9 ГБ у `~/Library/Application Support/Autodesk/webdeploy/production/<hash>/`).
- [ ] Сортування за розміром і датою останнього запуску, пошук за назвою.
- [ ] Позначати системні й захищені програми (`/System/Applications`, Apple, SIP) як такі, що видаляти не можна.

## Видалення програми

- [ ] Кнопка «Видалити програму»: підтвердження зі списком того, що буде видалено, і загальним розміром.
- [ ] Перед видаленням перевіряти, чи програма запущена; пропонувати завершити її (через наявне завершення процесів).
- [ ] Якщо в програми є власний деінсталятор (`Remove *.app`, `Uninstall *.app`, `*Uninstaller.app` поруч або в `~/Applications`), пропонувати запустити його першим. Після нього все одно переходити до перевірки залишків (деінсталятор Fusion лишив 5.4 ГБ).
- [ ] За замовчуванням переміщувати в Корзину; остаточне видалення лише за окремою опцією, як у наявному очищенні.
- [ ] CLI: `macjanitor apps list`, `macjanitor apps remove <bundle-id|шлях> --yes [--permanent]`, з `--dry-run` і JSON-виводом.

## Залишки після видалення

- [ ] Окремий розділ «Залишки»: шукати файли видаленої (або будь-якої вибраної) програми за bundle id, назвою програми й назвою розробника в:
  `~/Library/Application Support`, `Caches`, `Preferences` (`*.plist`), `Containers`, `Group Containers`, `Saved Application State`, `Logs`, `HTTPStorages`, `WebKit`, `LaunchAgents`; системні `/Library/Application Support`, `/Library/LaunchAgents`, `/Library/LaunchDaemons`, `/Library/PrivilegedHelperTools`.
- [ ] Кожен знайдений залишок показувати окремим рядком: шлях, розмір, чому він вважається залишком (збіг за bundle id, назвою, розробником), рівень впевненості.
- [ ] Видаляти залишки поштучно або вибраним набором, окремо від видалення програми.
- [ ] Не позначати як залишки спільні теки розробника, якщо в нього лишилися інші встановлені програми (напр. `Autodesk/Common`, коли стоїть EAGLE). Для таких показувати попередження замість автоматичного вибору.
- [ ] Знаходити «осиротілі» теки без жодної встановленої програми: дані розробника, від якого нічого не лишилось, plist-и без програми.
- [ ] Для LaunchAgents і LaunchDaemons: показувати, чи агент завантажений, і перед видаленням вивантажувати його (`launchctl bootout`).
- [ ] Залишки, що потребують прав адміністратора (системні `/Library/...`), позначати й видаляти лише після явного запиту на підвищення прав.
- [ ] CLI: `macjanitor apps leftovers [<bundle-id|назва>] [--orphans]` і `macjanitor apps leftovers --remove <шлях…> --yes`.

## Старі версії й великі службові дані (з ручного прибирання 2026-11-13)

- [ ] Знаходити теки налаштувань старих версій програм з версією в назві (JetBrains: `WebStorm2023.1`…`2026.1`, лишити поточну за версією встановленої програми; було 9 ГБ). Також логи старих версій у `~/Library/Logs/JetBrains`.
- [ ] Показувати великі образи VM і службові бандли програм з поясненням, що це і чи завантажаться вони заново (Claude Desktop `vm_bundles/claudevm.bundle`, 10 ГБ, нерозріджений `rootfs.img`).
- [ ] Перевіряти, що програма закрита, перед видаленням її даних (WebStorm, Claude Desktop).

# Запитати ШІ — план

Пояснення процесів і папок через ШІ, встановлені на машині (CLI з власним логіном, ключі застосунок не зберігає). Підхід і прапорці — як у `lang-switch/main.swift` (`discoverClaudeCLI`, `claudeCLIArguments`, `codexCLIArguments`, `runCLI`). Реалізовувати по одному пункту за раз.

## Бекенди

- [ ] Модуль `AI` з двома провайдерами: Claude Code (`claude`) і Codex (`codex`). Автопошук бінарника в `~/.local/bin`, `/opt/homebrew/bin`, `/usr/local/bin`, `~/.npm-global/bin`; якщо шлях задано в налаштуваннях — лише він.
- [ ] Запуск `claude` без інструментів і чужих налаштувань: `-p --output-format text --system-prompt … --tools "" --strict-mcp-config --disable-slash-commands --setting-sources project --no-session-persistence`, `--model` лише якщо задано. Порожня тимчасова робоча тека, мінімальне оточення (`HOME`, `USER`, `LOGNAME`, `PATH`, `LANG`) — без `USER` CLI не знаходить логін у Keychain.
- [ ] Запуск `codex`: `exec --sandbox read-only --skip-git-repo-check --ephemeral --ignore-user-config --ignore-rules -c project_doc_max_bytes=0 -C <work> --output-last-message <file> -`, інструкції й питання в stdin.
- [ ] Тайм-аут (120 с) і скасування: закриття вікна відповіді вбиває процес (SIGTERM, через 2 с SIGKILL).
- [ ] Зрозумілі помилки: CLI не знайдено, не залогінено (підказка `claude` / `codex login` у Терміналі), тайм-аут, порожня відповідь.
- [ ] Перевірка (тест): аргументи й оточення для обох CLI, автопошук з підміненою перевіркою виконуваності.

## Налаштування
